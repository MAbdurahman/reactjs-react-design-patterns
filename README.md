# reactjs-react-design-patterns

<p>React is all about building things in a smart, organized way. These design patterns 
are like handy guides that help you do just that. Whether you're new to React or a 
seasoned coder, these React Design patterns are like your trusty tools to make your
code not just work but work really well.</p>

## Some common challenges that a React developer faces are:

- Creating reusable components
- Uncontrolled and controlled component in form handling
- Reusing complex logic between multiple components
- To solve the above issues, we need React Design Patterns

## Here are 7 React Design Patterns every develop should know

- Layout Components Pattern
- Conditional Rendering Pattern
- Higher Order Components (HOC) Pattern
- Provider Pattern
- Presentational and Container Component Pattern
- Render Props Pattern
- Compound Pattern
